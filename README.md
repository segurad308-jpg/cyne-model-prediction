# Cyanobacteria Bloom Prediction — Lake Greifensee & Neuchâtel

A machine learning project that predicts the probability of cyanobacteria blooms in Swiss peri-alpine lakes. The model is trained on daily monitoring data from Lake Greifensee (EAWAG) and applied to Lake Neuchâtel via a set of transposable weather features.

## Background

Cyanobacteria blooms pose health risks in Swiss lakes. In deep peri-alpine lakes, the dominant species (*Planktothrix rubescens*) lives in deeper layers during summer stratification and gets mixed to the surface in autumn and winter — the opposite of the usual warm-weather bloom pattern. This project captures that dynamic using environmental and meteorological features.

## Data

The raw dataset is not included in this repository. Download `ctd_meteo_SPC_2019to2021_0to8m.csv` from:

> [EAWAG Datalakes — Greifensee forecasting dataset](https://opendata.eawag.ch/dataset/data-for-dl-forecasting)

Place it in `data/raw/`. Weather data for Lake Neuchâtel is fetched automatically from the [Open-Meteo Historical API](https://open-meteo.com/) (free, no key required).

## How to run

```bash
pip install -r requirements.txt

# 1. Build the dataset
python src/build_dataset.py

# 2. Open the notebooks in order
# notebooks/greifensee_analysis.ipynb   → Greifensee model
# notebooks/cyne.ipynb                  → Neuchâtel application
```

## Results

| Model | Features | ROC-AUC |
|---|---|---|
| Logistic Regression | Full (in-lake) | 0.68 |
| Random Forest | Full (in-lake) | **0.90** |
| Logistic Regression | Transposable (weather only) | 0.65 |
| Random Forest | Transposable (weather only) | **0.82** |

The Random Forest with full in-lake features reaches a ROC-AUC of 0.90 on Greifensee. The transposable model (weather + season only) drops slightly to 0.82 but can be applied to any lake with Open-Meteo coverage.

## Limitations

The Neuchâtel results are an **extrapolation by analogy** — the model was not validated against real Neuchâtel measurements. Absolute probability values are inflated by the balanced class weights; interpret the seasonal shape, not the exact numbers.
